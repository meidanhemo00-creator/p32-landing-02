# P32

The P32 company website. Next.js (App Router) + TypeScript + Tailwind CSS +
GSAP.

See `DESIGN.md` for the design system, type substitution note, and motion
architecture decisions.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm run start
```
